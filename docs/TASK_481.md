## Реализация и совместимость

Добавлен `facts[]` с полями `text`, `line`, `source_url`, `fetched_at`, `status`
и необязательной `reason`. Это утверждения воркера с состоянием доказательств:
`ok` — HTTP 200 и совпавшая цитата; `unavailable` — неудачная попытка либо явное
сообщение воркера; `partial` — недостаточная проверка (нет цитаты, цитата не
найдена, адрес неизвестен). Время поставляет код после попытки, без попытки —
`null`; время публикации и время из ответа модели не подставляются. Локальные
находки используют `path:line` и время обработки отчёта, без сетевой проверки.

У воркера добавлены `source_url` (единственный известный источник, иначе `null`),
`fetched_at` (время сбора отчёта) и расширен `status`. У фактов нескольких
источников ссылки и времена раздельны. Существующие `text`, `sources` с `url/title`,
`sourceVerification` с числовым HTTP-статусом, usage и остальные поля сохранены.
CLI по-прежнему возвращает `{markdown, report}`, MCP — `content` и
`structuredContent`; SERP, зависимости и адаптеры провайдеров не менялись.

Недоступность принимается из результата провайдера (`status: unavailable`,
`sources[].status`) или текстовой записи `status=unavailable (URL)`. Объявление
`ok` не заменяет проверку HTTP/цитаты. При HTTP-сбое, сетевой ошибке, таймауте
или блокировке адреса факт получает `unavailable`. Существующие причины
`sourceVerification` сохранены; отсутствие запроса и неудачный запрос теперь
различаются полями статуса и времени факта.

В аудит, критику и синтез передаётся текст без недоступных утверждений, включая
продолжения пункта списка. При смешанных метаданных источников также исключаются
утверждения без ссылки: их нельзя достоверно отнести к доступной странице.
Прежний диагностический текст остаётся в отчёте. После фильтрации отказов в
раунде критики номера строк фактов пересчитываются, чтобы исключение утверждений
не сместилось на другую строку. Новые метаданные проходят те же data-обёртки.

`report.unavailableSources` содержит URL, id воркера, время и причину каждого
пробела (повторы URL убираются внутри одного воркера). Синтез получает этот
список и запрет догадок. Дополнительный раздел о неполноте формируется кодом,
поэтому пропуск предупреждения моделью не скрывает пробел. Если все данные
явно недоступны, возвращается неполный ответ; прежняя ошибка при полном
техническом отказе всех воркеров сохраняется.
